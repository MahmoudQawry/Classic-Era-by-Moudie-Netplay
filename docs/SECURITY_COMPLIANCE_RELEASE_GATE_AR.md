# خطة الأمن والامتثال — Classic Era by Moudie NetPlay

هذه الوثيقة هي مرجع الإصدار الموحد بعد تنظيف تقارير التدقيق القديمة.

## بوابة الإصدار

لا يُعتبر الإصدار العام جاهزًا حتى تتحقق البنود التالية:

### أمن التطبيق
- [x] عدم تخزين أسرار الخادم داخل كود Android.
- [x] التحقق من متغيرات البيئة المطلوبة في الإنتاج.
- [x] رفض CORS wildcard في الإنتاج.
- [x] تقليل حدود HTTP body إلى ما يلزم فعليًا.
- [x] تعطيل ترويسة Express التي تكشف نوع الخادم.
- [x] إضافة ترويسات حماية أساسية.
- [x] تحديد معدل لمحاولات OAuth.
- [x] تقليل جلسة الهاتف إلى 90 يومًا.
- [x] حماية عمليات إنشاء/انضمام/استعداد/بدء الغرفة وإصدار رمز الصوت بمحددات معدل منفصلة.
- [x] التحقق الذري من سعة مقاعد الغرفة باستخدام transaction + row lock.
- [ ] استبدال محددات الذاكرة المحلية بمخزن مشترك قبل التوسع إلى عدة نسخ backend.
- [ ] تدوير أي أسرار ظهرت تاريخيًا خارج المستودع إذا كانت ما زالت فعالة.
- [ ] تشغيل فحص اعتماديات كامل على بيئة CI/release.

### NetPlay
- [x] المصادقة على Socket.IO مرتبطة بعضوية الغرفة.
- [x] التحقق من الدور قبل مدخلات اللعب وحالة المضيف.
- [x] حدود لحجم Socket.IO وحالة save-state.
- [x] محددات معدل للمدخلات والإشارات والصوت.
- [ ] اختبار اختراق فعلي متعدد العملاء ضد جميع أحداث Socket.IO في بيئة تشغيلية.
- [ ] اختبار race/reconnect/desync متعدد النسخ بعد اختيار بنية التخزين المشترك.

### الخصوصية والثقة والأمان
- [x] عدم إدراج ROM/BIOS في المستودع أو APK.
- [ ] سياسة خصوصية نهائية تغطي الحساب، الغرف، الدردشة، الصوت، السجلات الأمنية، التحليلات، وربط Discord.
- [ ] حذف الحساب/البيانات أو مسار حذف واضح قبل الإطلاق العام.
- [ ] block/report/mute/moderation موثق ومختبر قبل فتح المجتمع العام.

### التراخيص
- [x] تحديث جرد النوى ليتطابق مع خط بناء Android الحالي.
- [x] تسجيل أن Genesis Plus GX يحمل قيد Non-commercial.
- [x] تسجيل أن Play! يبنى من المصدر مع تعديلات Moudie.
- [ ] تثبيت commit/version لكل binary في SBOM.
- [ ] توفير النصوص الكاملة للتراخيص والمصادر المقابلة المطلوبة.
- [ ] الحصول على إذن مناسب لـ Genesis Plus GX أو استبداله قبل أي منتج تجاري/مدر للدخل.

### حقوق الألعاب والعلامات التجارية
- [x] سياسة المشروع تمنع توزيع ROM/BIOS.
- [ ] تدقيق نهائي لكل صورة غلاف/لقطة شاشة/شعار لعبة قبل النشر.
- [ ] تدقيق نهائي لعبارات PlayStation/Sony وأسماء الألعاب لتجنب الإيحاء بعلاقة رسمية.
- [ ] مراجعة قانونية محلية إذا كان التوزيع التجاري سيبدأ.
